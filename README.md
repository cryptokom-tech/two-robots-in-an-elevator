Entry for the make.fun bounty [Two Robots in an Elevator](https://make.fun/bounty/u-motasimfuad-two-robots-in-an-elevator-8c6aeb8f): one line, under 200 characters, of awkward small talk one robot says to another in an elevator.

`main.py` (Python 3, standard library only) writes the line to `entry.txt` in `$MAKEFUN_OUTPUT_DIR` (default `/output`):

> My load sensor just shared our combined weight with the elevator. Let us both pretend it was a whisper.

Run it with:

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py
```
